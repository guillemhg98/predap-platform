Use GitHub Issues for public questions, documentation fixes and reproducible
bugs that do not include private data.

## Security, Privacy and Sensitive Data

Do not post secrets, real healthcare data, production predictions, model
artifacts trained on real data, MLflow artifacts or screenshots containing
private information in public issues.

For a suspected vulnerability or data exposure, follow `SECURITY.md` and use a
private maintainer channel.

## Good Bug Reports

Include:

- repository name;
- command that failed;
- operating system;
- Python, Docker and dependency versions when relevant;
- sanitized error output;
- whether the issue appears with toy data, real data or both.
